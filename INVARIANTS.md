# SimCom - Инварианты системы

Проверяются в `check_invariants()` после каждой инструкции. Если что-то падает - смотри сюда.

---

## I-1. Стек

`2 ≤ sp ≤ SS_START`

`SS_START = 171` - пустой стек. Ниже 2 не опускаемся: адреса 0–1 забиты под IVT, затирать их стеком - плохая идея.

После симметричных `PUSH`/`POP` и `CALL`/`RET` указатель обязан вернуться в `SS_START`. Не вернулся - утечка.

```python
# FIXME: нижний порог 2 придется поднять, если IVT разрастется
assert 2 <= self.registers['sp'] <= SS_START
```

**v1.8:** Выпилили промежуточный регистр в `CALL` - он тихо затирал `AX`. Адрес возврата должен лежать строго на стеке, нигде больше.

## I-2. Защита кода (MMU)

`MOV` пишет только в `DS_START ≤ addr < CS_START`

Сегмент кода (`addr ≥ CS_START = 342`) и системная область (`addr ≤ 1`) для `MOV` закрыты. Стек - только через `PUSH`/`POP`, и никак иначе.

Проверка через `isinstance` - да, костыль, но зато сразу видно, если в сегмент кода прилетело число вместо инструкции. Нормальная ячейка кода - это список или пустая строка, `int`/`float` там быть не должно физически. Если есть - state inconsistency, дальше не идем.

```python
for addr in range(CS_START, MEM_SIZE):
    assert not isinstance(self.memory[addr], (int, float))
```

## I-3. ALU (16-битная арифметика)

`math_op` режет все до `[-32768, 32767]`. `OF = 1` - было обрезание. Флаг выставляем для совместимости, по факту на него никто особо не смотрит.

```python
for reg in GP_REGS:
    assert -32768 <= self.registers[reg] <= 32767
```

**v1.2:** `ZF` не сбрасывался после `MOV`. Граница между ALU и data transfer была размытой, поймали случайно.

## I-4. Указатель инструкций

`CS_START ≤ ip < MEM_SIZE` пока `is_run = True`

Прыжок за пределы `CS` - падаем по ассерту. После `HLT` значение `ip` не проверяем.

```python
if self.is_run:
    assert CS_START <= self.registers['ip'] < MEM_SIZE
```

**v1.7:** `LOOP` с `CX = 1` прогонял тело лишний раз - порядок был «прыжок → декремент» вместо «декремент → прыжок». Добавили отдельный тест на `CX = 1`.

## I-5. Сегментные регистры

`cs = 342`, `ds = 172`, `ss = 171` - константы, менять их нечем, но ассерт пусть висит.

```python
assert self.registers['cs'] == CS_START
assert self.registers['ds'] == DS_START
assert self.registers['ss'] == SS_START
```
